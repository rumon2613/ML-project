# Data

This folder is used to store the datasets for the machine learning project.

## Current Dataset Status

Currently, no external dataset has been added to this project. The notebook uses small example datasets created directly in the Python code for practice and demonstration.

## Data Description

The current example data includes:

* Student marks
* Student study hours
* Sleep hours
* Attendance
* Snacks
* Pass/Fail status
